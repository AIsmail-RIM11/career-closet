CAREER CLOSET — INSTALL & PUBLISH (November 2026)

This is a new static implementation of the Career Closet Capstone prototype.
It is not a direct export or edit of the original React/Vite code.
There are no Markdown documents, AI-builder instructions, generated branding,
external JavaScript libraries, npm installs, or build steps in this package.

TO REPLACE THE FILES IN YOUR EXISTING GITHUB REPOSITORY

1) Download Career_Closet_Updated_Clean.zip to your Mac's Downloads folder.
2) Open Terminal. Run the following commands, one line at a time:

cd ~/Downloads
git clone https://github.com/AIsmail-RIM11/career-closet.git
cd career-closet
git rm -r .
unzip -o ~/Downloads/Career_Closet_Updated_Clean.zip -d .
git add -A
git commit -m "Refresh Career Closet website and remove builder files"
git push origin main
bash publish.sh

If you've already cloned a folder called career-closet, use another directory
or clone elsewhere. Do not run 'git rm -r .' in any unrelated repository.
It only removes tracked files from the Git checkout, not the .git history.

The 'publish.sh' script updates the existing GitHub Pages gh-pages branch
without forcing or rewriting its history. No npm installation is required.

Live URL after GitHub Pages updates:
https://aismail-rim11.github.io/career-closet/

LOCAL PREVIEW

Open index.html directly in a browser, or from this folder run:
python3 -m http.server 8000
Then browse http://localhost:8000/

WHAT THIS DEMO IS — AND IS NOT

It demonstrates browse/filter, garment-specific sizing, outfit selection,
placeholder pickup information, demo appointment selection, local reservation,
QR handoff, staff lookup, and local pickup status.
It does not have real inventory, user accounts, verified hours/address,
actual bookings, or a synchronized backend.
